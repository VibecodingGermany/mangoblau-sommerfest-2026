# Mangoblau Sommerfest 2026

Planungsrepo für das Mangoblau Sommerfest der VibecodingGermany-Community.

## Eckdaten

- **Datum:** Samstag, 27.06.2026
- **Optionaler Ausklang:** Sonntag, 28.06.2026
- **Ort:** Mangoblau / Multimediahalle Oldenburg
- **Project Board:** https://github.com/orgs/VibecodingGermany/projects/2/views/1

## Zweck dieses Repos

Dieses Repo ist die zentrale Arbeitsablage für das Orga-Team. Aufgaben, Entscheidungen, offene Punkte und Rückmeldungen sollen hier nachvollziehbar bleiben, damit nichts im Chat verloren geht.

Das Repo wird genutzt für:

- Aufgabenplanung über GitHub Issues
- Status-Tracking im GitHub Project
- Diskussionen und Entscheidungen direkt an der jeweiligen Aufgabe
- Sammlung von Links, Angeboten, Checklisten und Ergebnissen
- Vorbereitung von Programm, Technik, Catering, Kommunikation und Sicherheit

## Arbeitsweise

Jede Aufgabe ist ein GitHub Issue. Bitte relevante Abstimmungen, Angebote, Links, Bilder und Entscheidungen direkt im passenden Issue kommentieren.

Der Chat bleibt für schnelle Hinweise sinnvoll, ist aber nicht die verbindliche Ablage. Verbindlich ist, was im Issue oder Project dokumentiert ist.

## Status

Im Project Board werden Aufgaben über das Feld `Status` gesteuert:

| Status | Bedeutung |
| --- | --- |
| Offen | Noch niemand arbeitet daran |
| In Arbeit | Aufgabe wurde übernommen |
| Wartet auf | Blockiert oder Rückmeldung fehlt |
| Erledigt | Fertig |

## Mitmachen im Orga-Team

Wer im Orga-Team mitarbeitet, sollte Zugriff auf Repo und Project haben:

- Repo-Recht: mindestens `Triage`, besser `Write` falls Dateien gepflegt werden sollen
- Project-Recht: `Write`, damit Status und Felder gepflegt werden können

Empfohlen ist ein GitHub-Team wie `sommerfest-orga`, das auf Repo und Project berechtigt wird.

## Kommunikationsregel

Bitte nicht nur im Chat entscheiden.

Wenn eine Information zu einer Aufgabe gehört, dann bitte im passenden Issue dokumentieren:

- Angebote
- Zusagen
- offene Fragen
- Entscheidungen
- Links
- Bilder
- Checklisten

So bleibt die Planung auch für Personen nachvollziehbar, die später dazukommen oder nicht jeden Chatverlauf gelesen haben.
